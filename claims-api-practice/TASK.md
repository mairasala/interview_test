# Task: claim status notifications

> Message from Product

Today a member has to open the app and check each claim to find out whether it was
approved or rejected. We want to tell them instead.

When something happens to one of their claims, the member should get a notification.
In the app there will be a bell icon with an unread count and a list of notifications,
and the member can mark them as read.

You can build it however you think is best.

## Ground rules

- 60 minutes, live, thinking out loud.
- TypeScript, in this repo. Use any tools you like, AI included.
- Follow the way the code is already written.
- The project should still pass `npm test` and `npm run typecheck` when you finish.

There is no UI in this repo. The API is what we are building.
